# OSL 概览

OSL（Origin Software Language）是一门树遍历解释执行的脚本语言。设计目标是：

1. **同步** —— 没有 Promise/async，读写文件、取窗口信息都直接返回值。
2. **可预测** —— 变量、作用域、错误传播规则简单且固定。
3. **能出错就报错** —— 拼错变量名、给常量赋值、把字符串当数字用，都会立刻抛错。

## 执行模型

```
源码 → lexer（缩进感知分词） → parser（递归下降，产出普通对象 AST）
     → Interpreter（树遍历求值）
```

- 缩进必须一致：4 个空格或一个 Tab 都行，同一文件内不要混用。
- 语句结尾不加分号；`;` 仅作为同一行内的语句分隔符。
- 每个窗口（每个应用实例）有独立的 `Interpreter`，全局变量互不影响。
- 一次解释执行有步数上限（默认 4,000,000 次求值）与递归深度上限（180），
  超限会抛错而不是冻结页面。

## 值类型

| 类型 | 字面量 | `type()` 返回值 |
| --- | --- | --- |
| 数字（双精度） | `42` `3.14` `1_000` `1e9` | `int` / `float` |
| 字符串 | `"hi"` `'hi'` `"""多行"""` `f"x = {x}"` | `str` |
| 布尔 | `True` `False` `true` `false` | `bool` |
| 空值 | `None` `nil` `null` | `None` |
| 列表 | `[1, 2, 3]` | `list` |
| 字典 | `{"a": 1}`，键可为任意值 | `dict` |
| 函数 | `fn(...)`、`x => ...` | `function` |
| 类 / 实例 | `class A:` / `A()` | `class` / 类名 |
| 错误 | `ValueError("x")` 的返回值 | `error` |
| 宿主对象 | `fs`、`sys`、`math` 等命名空间 | `object` |

字典底层是 `Map`，**保留插入顺序**，键按引用/原始值比较（不是深比较）。

## 真值规则

以下为假，其余为真：

- `None`
- `False`
- `0`、`0.0`
- `""`
- `[]`、`{}`（空列表、空字典）

注意 `"0"` 与 `"false"` 都是真值（非空字符串）。

## 相等

`==` 对列表和字典做**深比较**：

```osl
print([1, [2, 3]] == [1, [2, 3]])   # True
print({"a": 1} == {"a": 1})          # True
```

但字典的**键**使用 Map 的同一性语义，因此 `{"a": 1}` 与另一个 `{"a": 1}` 是
两个不同的键。需要按内容查找时，请遍历或使用字符串键。

`is` / `is not` 是同一性判断，等价于 JavaScript 的 `===` / `!==`。

## 类型转换

| 场景 | 规则 |
| --- | --- |
| `str()` / 字符串拼接 | 数字去掉多余小数位；`None` → `"None"`；`True` → `"True"`；列表/字典输出可读形式 |
| 算术与大小比较 | 接受数字、布尔、以及**可解析为数字的字符串**（`"3" - 1 == 2`） |
| `+` | 两个数字相加；两个列表拼接；任一侧是字符串则做拼接 |
| `None + 数字` | **抛错**（1.1 起），不再静默返回 `None` |
| `len()` | 字符串/列表/字典/宿主对象；`None` 返回 0 |

比较运算的一个已知细节：两侧都是字符串时按字典序比较，否则按数字比较。
因此 `"10" < 9` 为真，而 `"10" < "9"` 为真。

## 注释

```osl
# 整行注释
let x = 1   # 行尾注释
```

字符串里的 `#` 不会被当作注释。
