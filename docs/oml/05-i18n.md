# 多语言

OS 1.1 支持中文与英文界面，语言是可持久化的系统设置。

## 机制

```
src/i18n/index.ts
  ├─ zh        以英文原文为键的词典
  ├─ setLang() 由 SettingsStore.apply() 调用
  ├─ t(key, …) 显式翻译，供 OSL 使用
  └─ autoT     OML 渲染器对字面量文本自动调用
```

英文不建词典，原文即结果；中文缺词条时回退英文。

## OML：自动翻译

没有 `{}` 的文本属性会被当作消息 id：

```xml
<Label text="Files"/>                       <!-- 中文环境：文件 -->
<Button text="New folder" onclick="…"/>      <!-- 中文环境：新建文件夹 -->
<Input placeholder="Search…"/>               <!-- 中文环境：搜索… -->
```

覆盖的属性：`text`、`title`、`placeholder`，以及元素内部的纯文本节点。

含插值的字符串不会自动翻译（无法确定文案边界），需要显式 `t()`：

```xml
<Label text="{t('{0} items', count)}"/>
```

## OSL：显式调用

```osl
ui.toast(t("Refreshed"), "refresh")
win.setTitle(t("Notes") + " — " + paths.basename(path))
ui.confirm(t('Delete "{0}"?', name), onOk, t("Delete"))
```

`t(key, ...args)` 用 `{0}`、`{1}` 占位。占位符在译文中可以调换顺序。

```osl
# 词条：'{0} files · {1} used of 8 MB' → '{0} 个文件 · 已用 {1} / 8 MB'
text = t('{0} files · {1} used of 8 MB', count, size)
```

## 读取与切换

```osl
let current = lang()          # "en" / "zh"
let s = sys.settings()
let uiLang = s.get("lang")
sys.setSetting("lang", "zh")
```

切换语言后，`SettingsStore` 会通知内核，所有已打开窗口与外壳一起重绘，无需重启。

设置面板路径：设置 → 外观 → 界面语言。

## 新增一门语言

1. 在 `src/i18n/index.ts` 的 `Lang` 类型与 `LANGS` 数组里加一项。
2. 复制 `zh` 词典，翻译所有值，加入 `CATALOGUES`。
3. 在 `setLang()` 里映射新的语言码。
4. 在 `src/apps/settings/settings.osl` 的 `langs` 列表里加入该语言。
5. 设置面板的分段控件会自动出现新选项（`<For each="langs">`）。

## 注意事项

- 键是**精确的英文原文**，改动文案等于改键：旧译词会失效并回退英文。
  新增文案时请同步补词条。
- 不要翻译用户数据（文件名、笔记内容、终端输出）。自动翻译只作用于
  OML 里的字面量属性，不会碰 `{}` 求值结果。
- 字体栈已包含 PingFang SC 与 Microsoft YaHei，中文不需要额外加载字体。
- 日期时间：`time.format()` 输出英文缩写，需要跟随语言时用
  `time.intl(ts, style)`。
- 数字与单位目前按原文拼接，没有做复数规则处理。
